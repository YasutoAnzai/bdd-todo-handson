# A: 単一HTML版 TODO アプリ（依存ゼロ・Windowsでダブルクリック）

`index.html` を**ダブルクリック**するだけでブラウザで開きます。インストール・サーバ不要。
追加・完了（チェック）・削除・未完了件数の更新がその場で動きます（データは localStorage に保存）。

## 使い方

1. `index.html` をダブルクリック（またはブラウザにドラッグ&ドロップ）
2. やることを入力して「追加」
3. チェックで完了（取り消し線＋淡色）、「削除」で消える、上部の未完了件数が更新される

## BDD での位置づけ

このファイルには 2 つのレイヤーが同居しています。

- `TodoLogic`（`add` / `toggle` / `remove` / `pendingCount`）＝**外部I/Oなしの純粋ロジック**。
  → 評価レイヤー **(unit)**。この関数群だけを取り出してテストできる。
- 画面（入力→一覧→件数表示）＝**ブラウザ操作で確かめる振る舞い**。
  → 評価レイヤー **(client-medium)**。Playwright でブラウザを操作して表示を検証する。

同じ振る舞い「未完了が0件になる」を、unit（`pendingCount()===0`）でも
client-medium（画面の件数表示が 0）でも評価できる——これが「評価レイヤーを選ぶ」の実感です。
